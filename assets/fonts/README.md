# Fonts for the figures

TeX Gyre Heros (regular, bold, italic, bold italic), a free clone of Helvetica. IOP Publishing accepts only Times,
Helvetica, Courier and Symbol in figures, so the figures use this font (`src/ppg_bp/evaluation/plots.py`).

- Source: CTAN, https://mirrors.ctan.org/fonts/tex-gyre/opentype/ (downloaded 2026-10-21)
